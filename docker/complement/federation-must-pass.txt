# Complement federation tests that MUST pass — the regression gate.
#
# Federation coverage is still growing, so unlike csapi this is a positive
# ("must pass") list rather than an allowed-to-fail list: it locks in the
# top-level tests we've gotten green so a regression fails CI, while the
# long tail of not-yet-implemented features is free to keep failing. The
# job fails if any test below is missing from the run's passes or shows a
# `--- FAIL:` marker.
#
# When a federation feature lands and flips a test green, add it here. Do
# NOT add a test that only passes intermittently — fix the flake first.
# (Reviewed 2026-08-02 across 4 runs: the original 19 pass every run;
# TestMediaWithoutFileNameCSMediaV1 was deliberately left out — it passed
# only 1 of 4, the known media flakiness.)
#
# 2026-08-02, run 30770852233: +9 deterministic feature wins from the
# create-event (MSC4289/4291/4311), /event_auth, and send_join/leave-V2
# validation batches. These are pure-logic tests (no media/timing/network
# race), so a single green run is sufficient to gate them. Still-partial
# and NOT gated yet: TestJumpToDateEndpoint (needs federation fallback +
# topological tie-break), TestUnknownEndpoints (key-server router lacks the
# M_UNRECOGNIZED fallback), and the V1 send_join/send_leave variants (v1
# routes unregistered) — see docs/federation-conformance.md.
#
# Works for both the per-push (-skip deferred buckets) and the weekly
# unfiltered run: none of these live in a skipped bucket, and none is in
# the deferred set, so the gate behaves identically for both.
